C2ME-GPUWorldGen

手机端 Minecraft Java 版 GPU 加速世界生成模组

介绍

为骁龙8 Elite（Adreno 830）手机适配，基于 Fabric，给 C2ME 增加真正 GPU 噪声世界生成。

当前处于开发验证阶段，解决远距离坐标 float 精度丢失、影子模式、噪声接管等问题。

信息

  • 目标版本：Minecraft Java 26.3 / Fabric
  • 许可证：MIT
  • 仓库：github.com/ZQwyb/C2ME-GPUWorldGen

版本进度

  • v0.8.6：影子模式验收通过
  • v0.9.0：double-double 高精度坐标，解决远距离小数丢失
  • v0.10.1：GPU噪声接管修复
